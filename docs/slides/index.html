01 · O problema

Quem quer se organizar desiste antes de ver valor

Apps de controle financeiro exigem mudança de contexto: abrir app, navegar, preencher formulário, escolher categoria. O esforço diário supera o benefício a curto prazo — e o hábito não se forma.

"Já tentei planilha (esqueci de preencher),
já baixei app (parei na 2ª semana)."
— Carla, persona-alvo (PRD §2.1)

Como o Halo resolve

Canal primário no WhatsApp — onde a pessoa já está dezenas de vezes ao dia. Basta escrever: 

Mercado 87,30

A IA categoriza e arquiva. O usuário recebe a confirmação em segundos, sem abrir nenhum app novo.

Hipótese do MVP: pessoa em início de organização financeira mantém o hábito por ≥ 4 semanas quando a barreira é só uma mensagem.

02 · A IA no produto

A IA não é ferramenta — é o que torna o produto possível

De texto livre a dado estruturado

Mensagem do usuário → HttpGeminiClient.parseExpense() → JSON pronto para persistir: 

{
  "description": "Mercado",
  "amount": 87.30,
  "category_hint": "Mercado",
  "occurred_at": "2026-05-22"
}

Sem IA, o usuário teria que escolher categoria a cada gasto — recriando a fricção que o produto quer eliminar. A IA é estrutural ao produto.

Decisões de engenharia de prompt

  • Gemini 2.5 Flash — latência < 3s e baixo custo
  • temperature 0.2 — classificação, não criação
  • responseMimeType JSON — saída garantida estruturada
  • Categorias injetadas no prompt — vocabulário restrito ao banco
  • Sentinel NOT_EXPENSE — separa intenção de falha

Resiliência e observabilidade

  • Fallback heurístico (regex em Java): se a IA cair, o gasto ainda é salvo
  • Tabela ai_log: tokens, latência, custo e status por chamada

03 · Viabilidade técnica inicial

Stack enxuta, custo desprezível, base já em pé

Stack

  • Backend — Spring Boot 3.3 + Java 21 + JPA + Flyway
  • Frontend — React 18 + Vite + Tailwind (PWA mobile-first)
  • Dados — PostgreSQL 16, timestamps em UTC, UUID v7
  • WhatsApp — Evolution GO self-hosted via webhook
  • IA — Google Gemini 2.5 Flash via REST
  • Infra — Docker Compose em VPS única (Traefik + TLS)

Status

  • Fase 0: 100% concluída (T-001 → T-008)
  • Fase 1: pipeline IA + fallback + ai_log em pé
  • CI em cada PR: mvn verify + npm build
